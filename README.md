# Dimensionamento TAE IFRN

Sistema da DIDEPE/DIGPE para o dimensionamento quantitativo das vagas de técnico-administrativos em educação (TAE) entre as unidades do IFRN e para a definição dos cargos a partir do quadro atual e das propostas dos campi.

- Página única (`index.html`), publicada pelo GitHub Pages.
- Dados no Supabase (projeto `dimensionamento-ifrn`), tabela `public.docs` e bucket privado `propostas-campi`.
- O acesso exige a senha da conta de acesso do sistema. Sem login, o banco não entrega nenhum dado (RLS só para usuários autenticados).

Tipologias: Portaria MEC nº 327/2026, alterada pela Portaria MEC nº 666/2026.
